# Política de privacidade · Privacy policy

*Última atualização: 21 de novembro de 2026 · Last updated: November 21, 2026*

## Português

O TidyFlow (o app e a extensão de navegador) **não coleta, não envia e não vende dados**.

- A extensão lê, de cada download, a URL do arquivo, a página de origem, o título da aba,
  o caminho do arquivo e o tipo. Essas informações vão, por *native messaging*, apenas
  para o programa `tidyflow` instalado no seu próprio computador, que as guarda num banco
  local (`journal.db`) para aplicar as suas regras.
- Nada é enviado pela rede, nem ao autor nem a terceiros. Não há telemetria, anúncios ou
  contas.
- Downloads de janelas privadas nunca são informados.
- Para apagar tudo: desinstale a extensão e apague a pasta de dados do TidyFlow
  (`~/.local/share/tidyflow` no Linux, `~/Library/Application Support/TidyFlow` no macOS,
  `%APPDATA%\TidyFlow` no Windows).

Dúvidas: <https://github.com/Langendolff/TidyFlow/issues>

## English

TidyFlow (the app and the browser extension) **does not collect, transmit or sell any data**.

- For each download, the extension reads the file URL, the referring page, the tab title,
  the file path and its type. This information is sent, via native messaging, only to the
  `tidyflow` program installed on your own computer, which stores it in a local database
  (`journal.db`) to apply your rules.
- Nothing is sent over the network, to the author or to anyone else. There is no
  telemetry, no ads and no accounts.
- Downloads from private windows are never reported.
- To erase everything: uninstall the extension and delete TidyFlow's data folder
  (`~/.local/share/tidyflow` on Linux, `~/Library/Application Support/TidyFlow` on macOS,
  `%APPDATA%\TidyFlow` on Windows).

Questions: <https://github.com/Langendolff/TidyFlow/issues>
